# Tetracoord Explorer

Tetracoordinates engine, grapher, calculator, playground.

![tetracoord explorer preview](docs/img/tcoord_ccoord_displays_2022-08-06.png)

## Webpage driver

Launch the local webserver with `npm run dev` (or `build` + `start`).

## CLI driver

Run cli driver with `npx tcoord` to evaluate an arithmetic or logical expression with scalar and vector terms. 
See `npx tcoord -- --help` for all options.

The `tcoord` cli program is maintained and better documented at [ogallagher/tetracoord](https://github.com/ogallagher/tetracoord).
